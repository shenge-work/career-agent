## 一、一句话现状

## 三、30 秒复现（在已安装依赖的机器上）

```bash
cd v2
npm run db:migrate                      # 应用 drizzle/*.sql（停 dev 后执行更安全）
npm run seed:user -- --email me@local.test --password '<强密码>' --role admin
npm run dev                             # 5173 前端 / 3000 API
npm test                                # 94 通过 / 3 跳过
npm run build
```

浏览器打开 `http://127.0.0.1:5173`。若 `pgdata/` 已存在且含演示账号，先按 [04](./04-运行维护与后续路线.md) 的「内测前必做」处理，不要直接沿用演示口令。

## 四、归档边界与隐私

- 本目录**不含**真实候选人姓名、招聘者姓名、简历正文、聊天正文、API Key、飞书凭证。涉及验收产物时只描述体积、格式、页数与中文附件名，不落具体个人信息。

- 验收用的临时探针脚本保存在 `/tmp/rs-*.mjs`，**未入库、机器重启即失效**；需要复验时按 [03](./03-实施与验收全记录.md) 中的手法重新构造。
- 本轮**没有修订**旧设计文档（`docs/技术设计方案/多页面路由与技术栈重构-技术设计方案.md`），只在 [01](./01-背景与选型决策.md) 登记冲突与建议，正式修订仍列为待办。
- 本轮**没有改动** v1 源码；仓库根目录里 v1 的未提交改动属于更早的会话，与本轮重构无关。
