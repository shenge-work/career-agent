## 6. P4b · 图片版 PDF 分页契约

- Spike 确认链路：`makeCaptureClone → html2canvas → RB.computePageBreaks(cap.clone) → jsPDF 逐页 drawImage`；因需量真实 DOM，不能放进服务端 vm，改为「生成导出专用页 + headless Chrome CDP 真跑」。
- `legacy-export-html.ts`：内联 v1 CSS/JS bundle + 本地 vendor、DOM 哑元素兜底、`confirm/alert` 桩、payload `</script>` 转义、CSP `connect-src 'none'`；driver 自动 `applyImported → exportPDF → downloadPDFNow()`，并 monkey-patch `RB.getPageMetrics` / `computePageBreaks` 记录 `rootIsClone / rootW / rootH / breaks`。
- `image-pdf.service.ts`：`--remote-debugging-port=0` + `DevToolsActivePort` 取端口、Node 22 内置 WebSocket、`Browser.setDownloadBehavior`、轮询 `window.__RESULT__` 与下载文件、超时与 SIGKILL / 临时目录收尾；返回 `{ buffer, pages, pagesLabel, live, paging }`。
- API：`GET :id/pdf?mode=image`、默认矢量不变、`GET :id/export-page`。前端拆成「矢量 PDF（推荐，文字可选中）」「图片版 PDF（精确分页）」两个按钮。
- 验收：65 通过 / 3 跳过；三组变异有效（去转义 → XSS 红、去 DOM 兜底 → 结构红、去分页探针 → 契约红）；正式代码实测 **4,225,003 B / `%PDF-1.3` / 3 页**，契约 `rootIsClone=true`、克隆与预览同为 `794×2727`、断点 `[0, 1017, 2033, 2621]`；HTTP：矢量 987 KB vs 图片版 4.2 MB、导出页 869 KB、401/404 正确；CDP：三按钮齐全、iframe `.resume` 且 0 script、点图片版下载中文名 PDF 4.2 MB、运行时错误与非预期 4xx 均 0。

## 8. 错误与修复登记表（按性质分组，勿退回）

### 环境与选型
| 现象 | 根因 | 修复 / 结论 |
| --- | --- | --- |
| 系统级 PG 装不上 | 无 sudo、无 brew/docker、`/opt` 不可写 | 改用 PGlite（同方言） |
| `embedded-postgres` 安装 6m42s 才 99 MB | beta 版 + 337 MB 平台包 | 中止，不采用 |
| `node:sqlite` 虽可用 | 方言差异会逼着重写 schema | 不采用，仅作为环境可行性记录 |

### 框架 / 构建
| 现象 | 根因 | 修复 |
| --- | --- | --- |
| Vitest 报 `A dynamic import callback was not specified` | 用 `new Function('return import(s)')` 绕 PGlite ESM | PGlite 自带 CJS `dist/index.cjs`，改静态 `import { PGlite } from '@electric-sql/pglite'` |
| Vite 8 配置告警 | CJS 包里 `.ts` 配置含 ESM 语法、同时给了 `esbuild` 选项 | 配置改 `.mts`，移除 `esbuild.jsx` |
| NestJS 构造注入失败 | Vitest/esbuild 不发射 `emitDecoratorMetadata` | 所有构造参数写显式 `@Inject(TOKEN)` |
| POST 探测接口返回 201 | Nest 的 `@Post` 默认 201 | `@HttpCode(200)`（`ai/test`、`collect/chat`） |
| TS 判别联合不窄化 | `if (!norm.ok)` 在联合类型下不收窄 | 改 `if (norm.ok === false)` |
| 迁移脚本块注释提前闭合 | 注释里出现 `*/` 片段 | 改写注释表述 |

### 数据与并发
| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 跨用户同 id 会覆盖 | v1 id 由客户端生成，单列主键 | `0001` 改复合主键 `(user_id, id)` |
| 直接读写 `pgdata` 与 dev 冲突 | PGlite 是**进程内单连接**库 | 迁移/核查前先停 `npm run dev`，完成再重启 |
| 导入可能被 v2 编辑覆盖 | 无冲突策略 | 默认 `ON CONFLICT DO NOTHING`，`--force` 才覆盖 |

### 渲染与导出
| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 复用 vm context 会串数据 | v1 顶层 `let data` 是全局态 | 每次渲染新建 context；`ctx.window = ctx`；定时器成套 no-op |
| `</title><script>` 注入 | payload 不可信 | `escapeHtml` + CSP `script-src 'none'` |
| 页边距算成 0 | `Number(null) === 0` | `mmNum` 显式回退 14mm |
| 设了 header 却吞掉 404/401 | `@Res()` 语义 | `@Res({ passthrough: true })` |
| 导出主线程永久挂起 | `applyImported()` 里的 `confirm/alert` 弹窗 | 导出页桩掉对话框 |
| 加载 blob PDF 卡死 | 真 `pdfFrame` iframe | 用 DOM 哑元素兜底，靠 `.src` 感知完成 |
| CDP `Runtime.evaluate` 超时 | 5 MB base64 回传 | 调 `downloadPDFNow()` 让 Chrome 下载落盘，轮询只返回轻量值 |

### 前端与浏览器验证
| 现象 | 根因 | 修复 |
| --- | --- | --- |
| CDP 里 404 旧资源 | 无 favicon | `index.html` 内联 data-URI favicon |
| 改动「看起来没生效」 | 同 URL 重新 navigate 只做 fragment 导航，不重载资源 | 先 `about:blank` 再进目标 URL |
| 改 React 受控 input 无效 | 直接赋值不触发 React 的 value tracker | native value setter + `dispatchEvent(new Event('input',{bubbles:true}))`，按 label 文本精确定位字段 |
| 「停用 AI 配置」按钮失效 | 无 body 的 DELETE 带 JSON Content-Type → Fastify 400 | `api.ts` 只在 `init.body` 存在时声明 JSON |
| 采集同批重复被误合并 | 宽松去重集合包含了本批消息 | 宽松集合只从**既有消息**构建 |
| 断言太宽泛（iframe / 附件名） | 未验证真实行为 | 收窄为真实下载、`%PDF` 解码头与分页契约探针 |

## 10. 诚实降级与已知边界

- 找不到 headless Chrome → 矢量 PDF 返回 501 并提示浏览器打印另存，不静默失败。
- 没有 CDP 调试端口 → 采集返回引导 hint，不伪装成功。
- 未配置 AI → 状态接口如实报未配置，试用台禁用；`ai.config.json` 只读回退，显式停用优先。
- `validateBaseUrl` 不解析 DNS，**不防 DNS rebinding**；正式对外部署需在出口网关限制。
- `COOKIE_SECURE=false`、仅监听回环；当前安全模型只适用于 ≤10 人本机内测。
- `share_grants` 表已建但分享 API 未接入；N3 的「shareToken 无远程吊销」历史限制在 v2 里具备解决条件但尚未落地。
- 飞书 OAuth / 版本同步 / Device Flow 注册未迁移；AI 目前只有转发层，未接 JD 派生 / 润色等写作流程。
- v2 不支持 `file://` 单文件离线版与 Tauri 壳；v1 仍保留该能力。
